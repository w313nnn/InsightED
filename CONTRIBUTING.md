# Contributing to InsightED

See [Team permissions](TEAM_PERMISSIONS.md) for project credits and the team's fork permissions.

## Propose a change

1. Create a feature branch from `main`, or work on a branch in your fork if that is your contribution workflow.
2. Keep the change focused and run any relevant checks.
3. Open a pull request targeting `main`. Describe what changed, why, and how you checked it.
4. Wait for the repository owner to review and merge the pull request. Address any feedback on your feature branch.
